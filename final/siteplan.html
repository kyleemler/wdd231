Individual Project Site Plan

SĒK Esthetics and Wellness

A clean, welcoming website plan for a spa and wellness business focused on services, professionals, and client interest.

Site Name

SĒK Esthetics and Wellness

This name was selected because it represents the business directly and clearly communicates that the website is focused on esthetics, spa services, and wellness. The name is professional, simple, and appropriate for a beauty and wellness brand.

Optional domain: sekesthetics.com

Site Purpose

The purpose of the website is to promote SĒK Esthetics and Wellness and give potential clients information about the spa, the services offered, and the professionals who work there. The site will help visitors learn about services such as facials, waxing, massage therapy, lashes, brows, and nails.

Target Audience

The target audience is people looking for beauty, spa, and wellness services. This includes clients interested in facials, waxing, massage therapy, lashes, brows, nails, and learning more about the professionals who provide those services.

Scenarios

  • What services does SĒK Esthetics and Wellness offer, and which service category fits my needs?
  • Who are the professionals at the spa, and what services does each person provide?
  • How can I show interest in booking a service or learn more before scheduling?

Data and API Plan

The site will use a local JSON file instead of a public API to keep the project focused and manageable. The Fetch API will load information about professionals from the JSON file and display that information dynamically on the professionals page.

JavaScript Features

  • Fetch API for loading professional data from a local JSON file
  • try/catch error handling for data loading
  • Dynamic content generation for professional cards
  • Event listeners for buttons, forms, and modal interactions
  • Local storage to save the user's preferred service category
  • Modal dialog for additional professional information
  • Array methods such as forEach()
  • Template literals for building reusable HTML output

Typography

Times New Roman

Used for the site title, page headings, and section headings to match the logo-inspired style.

Arial

Used for body text, navigation, buttons, form labels, cards, and supporting content because it is simple and readable.

Wireframe

The home page layout will introduce the business, show featured service categories, and guide visitors toward learning about services or professionals.
